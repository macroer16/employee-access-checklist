# Employee Access Checklist
A student portfolio demo for secure employee onboarding and offboarding workflows.

## Features
- New starter and leaver checklists
- Microsoft 365-style account, MFA, licence and access steps
- Device security and asset-return steps
- Progress saved in browser localStorage
- Printable demo checklist

## Security concepts
Least privilege, MFA, access removal, endpoint protection, encryption awareness and audit records.

## Limitation
This is a simulated front-end project only. It does not connect to Microsoft 365, Intune, Azure AD, or real employee accounts. Do not enter real data.
